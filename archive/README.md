# Historical sorting material

These files were moved on November 13, 2026, without changing their contents.
[manifest.json](manifest.json) records each original path, archived path, size
and SHA-256. It includes pre-existing notebook edits/outputs, preserved verbatim;
review/clear private outputs separately before sharing the archive publicly.

- `notebooks/`: former manual/automatic workflows, exploratory notebooks, empty
  CSC placeholder, saved curation JSON and the root loader notebook. Relative
  imports/data paths reflect their original locations; these are reference
  artifacts, not supported run entry points. Use `notebooks/central_sorting.ipynb`
  at the repository root for new work.
- `docs/`: earlier plans, review reports, implementation briefs, original guides,
  installation/config notes and workstation/cloud instructions. Their claims and
  links are historical; use the current root README and docs API for current use.

Importable compatibility code is intentionally kept in
`src/sorting_scripts/legacy/`, not copied here. Existing `sorting_scripts.zsort`
and `sorting_scripts.box_managment` names still work. Original sibling project
code and scientific results have not been deleted or relocated.
